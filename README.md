# matrices
El proposito principal del siguiente programa es realizar operaciones entre matrices, funciona con el comando %%writefile y guarda cada modulo en la estructura proyecto_matrices, cuenta con cuatro modulos, donde cada uno ejecut una accion especifica.
* El archivo main.py, es el programa principal, donde se importan los demas modulos, muestra el menú, pide matrices al usuario, llama a las funciones correspondientes, ejecuta el programa y termina cuando el usuario elija salir.
* El segundo modulo es operaciones_matrices.py, donde el usuario puede escoger que operacion realizar con la matriz dada al principio. El programa tiene suma, multiplicacion, producto Hadamard y producto kronecker. 

* En el tercer modulo (entrada.py) le permite al usuario ingresar dos matrices A y B de n dimensiones, para luego imprimir las dos matrices.
* El cuarto y ultimo modulo es menu.py, donde le brinda cinco opciones al usuario sobre que operacion desea realizar, para escoger una, debe ingresar uno de los numeros que aparecen en el menu segun corresponda.

La quinta carpeta, llamada "solucion" contiene el codigo que ejecuta el programa.
